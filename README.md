# صلاتي 🕌 - مواقيت الصلاة في مكة المكرمة

تطبيق آيفون SwiftUI يعرض مواقيت الصلاة الخمسة في **مكة المكرمة** بدقة حسب طريقة **أم القرى**، مع التاريخ الهجري والميلادي وعدّ تنازلي للصلاة القادمة.

## 📱 المميزات

- ✅ مواقيت الصلاة الستة: الفجر، الشروق، الظهر، العصر، المغرب، العشاء
- 🕋 ثابت على **مكة المكرمة** (Asia/Riyadh) - طريقة أم القرى (method 4)
- ⏳ عدّ تنازلي حي للصلاة القادمة مع شريط تقدم
- 📅 التاريخ الهجري والميلادي من API مباشرة
- 🔔 تنبيهات محلية لكل صلاة (تطلب الإذن تلقائياً)
- 🧭 شاشة القبلة (مبسطة)
- 🎨 تصميم إسلامي عصري - دعم كامل للغة العربية RTL
- 📶 يعمل بدون إنترنت (يخزن آخر مواقيت + بيانات افتراضية)

## 📂 هيكل المشروع

```
صلاتي/
├── Salati.xcodeproj/project.pbxproj   # مشروع Xcode جاهز
└── Salati/
    ├── SalatiApp.swift                 # نقطة الدخول
    ├── ContentView.swift               # الواجهة الرئيسية + Qibla
    ├── Models/PrayerTimes.swift        # نماذج البيانات + Helpers
    ├── Services/PrayerService.swift    # جلب المواقيت من Aladhan API
    ├── ViewModels/PrayerViewModel.swift
    ├── Views/
    │   ├── HeaderView.swift            # الرأس + الساعة الحية + التاريخ
    │   ├── NextPrayerCard.swift        # كرت الصلاة القادمة
    │   └── PrayerRow.swift             # صف كل صلاة
    └── Assets.xcassets/
```

## 🔌 API المستخدم

```
https://api.aladhan.com/v1/timingsByCity/{dd-MM-yyyy}?city=Makkah&country=Saudi Arabia&method=4
```
- `method=4` = جامعة أم القرى، مكة
- `timeZone = Asia/Riyadh`
- مجاني بدون مفتاح

## 🚀 طريقة التشغيل

### على Mac (Xcode 15+)
1. انسخ مجلد `صلاتي` إلى جهاز الماك
2. افتح `Salati.xcodeproj` بالضغط المزدوج
3. اختر Simulator (iPhone 15 Pro مثلاً)
4. اضغط `Cmd + R` للتشغيل

> **ملاحظة وأنت على Windows الآن:** مجلد المشروع جاهز في `C:\Users\DELL\Desktop\صلاتي`
> لكن لا يمكن تشغيل محاكي الآيفون على ويندوز مباشرة. تحتاج Mac أو خدمة مثل MacStadium / Codemagic للبناء.

### بدون Mac - حلول بديلة
- **Swift Playgrounds على iPad:** انسخ ملفات `Salati/` إلى مشروع جديد
- **Codemagic / EAS Build:** ارفع المشروع لـ GitHub وابنِ IPA عن بعد

## 📸 وصف الواجهة

1. **الرأس:** شعار "صلاتي" + ساعة مكة الحية + التاريخ الهجري/الميلادي
2. **كرت الصلاة القادمة:** اسم الصلاة، وقتها، ومتبقي `hh:mm:ss` مع شريط تقدم
3. **الأزرار السريعة:** الموقع (مكة)، التنبيهات، القبلة
4. **قائمة الصلوات:** 6 صفوف مع تمييز القادمة (أخضر) والحالية (ذهبي)
5. **آية:** «إن الصلاة كانت على المؤمنين كتاباً موقوتاً»
